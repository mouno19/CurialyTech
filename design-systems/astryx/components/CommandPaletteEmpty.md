# CommandPaletteEmpty

empty state; auto-rendered by palette when a search has no results, or no query and bootstrap() returns nothing

**Import:** `import {CommandPaletteEmpty} from '@astryxdesign/core/CommandPalette';`

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | message or content to display **(required)** |
