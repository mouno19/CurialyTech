Calendars
Show dates in the Persian, Hebrew, Hijri, Buddhist, Japanese, Chinese, Dangi, and other calendars while values stay
Gregorian ISO dates.

package: @astryxdesign/cli

`Calendar`, DateInput, DateRangeInput, and DateTimeInput show the Gregorian calendar unless the application chooses
another one. Values never change with the calendar: they stay Gregorian ISO dates. `astryx docs
internationalization/i18n-calendars` has the short version.
