# Radius Tokens

border radius tokens.

## Radius

Numeric scale based on a 4dp base unit. Tokens scale with the theme's radius multiplier; --radius-none and --radius-full are fixed.

Token              | Core default
------------------ | ------------
--radius-none      | 0px
--radius-inner     | 4px
--radius-element   | 8px
--radius-container | 12px
--radius-page      | 28px
--radius-chat      | 28px
--radius-full      | 9999px
