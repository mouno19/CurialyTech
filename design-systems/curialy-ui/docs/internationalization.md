Internationalization
Set the active locale, load catalogs, coexist with your own i18n library, show other calendars, handle RTL, and test
translations.

package: @curialy/ui

Guides

i18n-quick-start          Wrap your app in InternationalizationProvider, load a locale catalog, and swap languages at
                          runtime.
i18n-library-integration  Override cui's default text, coexist with react-intl / i18next / next-intl / LinguiJS, or
                          use cui as your i18n library.
i18n-calendars            Show dates in the Persian, Hebrew, Hijri, Buddhist, Japanese, and other calendars while values
                          stay Gregorian ISO dates.
i18n-rtl-and-testing      Text direction (RTL), pseudo-locale testing, and contributor guidance for developers and
                          translators.
