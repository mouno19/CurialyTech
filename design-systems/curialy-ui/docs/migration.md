Migration
Migrate an existing Tailwind, shadcn, or Radix app to the design system incrementally - setup, component replacement,
and verification.

package: @curialy/ui

Guides

migration-setup         Install the theme, wire CSS layers, audit resets, and run the foundation smoke test before
                        migrating any surface.
component-migration     Move the app frame first, map shadcn and Radix primitives to components, and wire up command
                        palette, settings, and theme controls.
migration-verification  Post-migration verification checklist and an AI migration prompt to paste into your coding tool.
