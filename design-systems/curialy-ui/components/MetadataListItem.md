# MetadataListItem

single labeled value in MetadataList

**Import:** `import {MetadataListItem} from '@curialy/ui/MetadataList';`

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | value content **(required)** |
| `label` | `string` | - | label text **(required)** |
| `icon` | `ReactNode` | - | icon before label |
