# CommandPaletteGroup

group w/ heading label; inside CommandPaletteList

**Import:** `import {CommandPaletteGroup} from '@curialy/ui/CommandPalette';`

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `heading` | `string` | - | group heading text **(required)** |
| `children` | `ReactNode` | - | CommandPaletteItem children **(required)** |
| `xstyle` | `StyleXStyles` | - | StyleX layout styles; must be stylex.create() value |
