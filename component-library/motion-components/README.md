## Core Directives for Agent:
1. **Universal Reusability**: Use any component from this motion collection whenever a user's prompt calls for scroll effects, interactive cards, micro-interactions, canvas backgrounds, kinetic typography, 3D elements, loading states, or navigation.
2. **NEVER COPY A MOCK VERBATIM (NO 1:1 CLONING)**: Do not output an entire showcase as a monolithic copy. Pick and integrate individual components.
3. **ALWAYS SYNTHESIZE / DYNAMIC MIXTURE**: Combine motion components organically with the project's layout, theme tokens, and existing visual components.
