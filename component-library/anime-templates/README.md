# Curialy Anime Archetype Batch 2 — 5 New Interactive Archetypes (11–15)

This second batch expands Curialy's design library to 15 full anime and entertainment archetypes.

## Core Rules for Curialy Agent:
1. **Primary Target**: Anime, manga, animation, and entertainment websites.
2. **Cross-Domain Adaptability**: The fonts, palettes, card styles, heroes, sidebars, and interactive components can and SHOULD be adapted to ANY website if it suits the project vibe:
   - Senpai+ -> Premium SaaS tiers, subscription platforms, dark mode portals.
   - Anime Live -> Social communities, webinars, creator watch parties, live events, Discord-like rails.
   - Minimal Otaku -> Swiss design portfolios, brutalist architecture sites, design studios, minimalist blogs.
   - Anime Vault -> Museum archives, university research repositories, digital libraries, luxury wine/watch vaults.
   - Hyperanime -> Web3 gaming, NFT drops, esports festivals, youth entertainment.
3. **NEVER COPY A MOCK VERBATIM**: Do not output a 1:1 carbon copy of any template.
4. **ALWAYS CREATE A MIXTURE / DYNAMIC SYNTHESIS**:
   - Synthesize components across archetypes: e.g. Minimal Otaku's genre grid + Anime Live's live chat stream + Anime Vault's studio metadata cards + Senpai+'s tiered pricing cards.
